# 统一原型外壳 · 两个模块一个侧边栏

> 把「基础支撑管理」和「数据可视化系统」装进同一个应用：**一个侧边栏、一个顶栏、一套面包屑**，侧边栏可折叠。
> 声明：纯前端演示，无后端、无真实数据。

---

## 1. 打开方式

双击 `index.html`，Edge / Chrome 直接打开，不用起服务。

- 默认进入「基础支撑管理 / 平台能力」。
- 支持深链接：`index.html#/bs/apps`、`index.html#/viz/quality`。
- 两个模块的独立原型仍然保留：`../prototype/index.html`、`../prototype-viz/index.html`。

目录：

```
prototype-all/
├─ index.html   外壳（侧边栏 + 顶栏 + 内容区）
├─ shell.css    外壳样式
├─ shell.js     导航模型、折叠、路由、与内容区通信
└─ README.md
```

## 2. 侧边栏怎么用

### 折叠

- 点顶栏左上角 `«` 折叠成 68px 图标栏，再点 `»` 展开；
- 快捷键 **Ctrl / Cmd + B**；
- 刷新后保持上次状态（localStorage）；
- 折叠后鼠标悬停图标有名称提示。

### 模块手风琴

- 「基础支撑管理（9）」「数据可视化（11）」「评审工具（4）」三组；
- 点组标题展开/收起；
- 切换模块时，自动展开当前模块、收起另一个，避免侧边栏过长；
- 折叠状态下点组图标，会先展开侧边栏再打开该组。

### 评审工具集中放

两个模块的「业务规则清单」「待确认问题」统一放在第三组，评审时不用在模块之间来回找：

- 基础支撑 · 规则清单（56 条）
- 基础支撑 · 待确认（12 条）
- 可视化 · 规则清单（60 条）
- 可视化 · 待确认（12 条）

### 顶栏

- 面包屑：模块 / 页面，随内容区页面切换自动更新；
- 账号随模块切换（基础支撑是平台管理员张伟，可视化是分析师王分析）；
- 右上角 `↗` 把当前页面在新窗口独立打开；
- 移动端（≤900px）侧边栏变成抽屉，点遮罩关闭。

## 4. 建议的演示顺序

1. **基础支撑 / 应用接入**：新建接入 → 审核 → 发凭证（讲"能力怎么被申请"）。
2. **系统设置**：改一个敏感参数 → 审批 → 生效 → 回滚（讲"配置与留痕"）。
3. **操作记录**：翻刚做的操作（讲"每一步都留痕"）。
4. 切到 **数据可视化 / 经营总览**：点数字逐层查看、试数据延迟、点柱子一起筛选（讲"统计定义与消费"）。
5. **质量分析**：点质量波动图的红点 → 生成工单（讲"异常到闭环"）。
6. **展示屏设计**：缺字段发布被拦 → 补齐 → 审核发布（讲"发布校验"）。
7. **评审工具**：勾几条规则、选几个问题结论 → 导出清单（讲"怎么收敛需求"）。

## 6. 实现方式与边界

- 外壳负责导航、折叠、面包屑、账号与深链接；两个模块以独立页面嵌在内容区，各自保留原有逻辑与本地状态。
- 这样做的原因：两个模块的业务逻辑、路由、状态机完全不同，硬揉成一个文件会互相污染；外壳 + 独立页面既统一了体验，也保住了各自的可测试性。
- 因此有一个已知限制：**切换模块会重新加载内容区**（约 0.2 秒），切回时页面回到该模块上次的页面地址，但弹窗、抽屉这类临时状态不保留；业务数据存在各自 localStorage 里，不受影响。
- 折叠、分组展开状态、当前页面都会记住。

## 7. 自测情况

Edge 无头浏览器 **28 项检查**：

- 默认进入基础支撑 / 平台能力，深链接生效；
- 折叠 / 展开、宽度变化、Ctrl+B、刷新后保持；
- 分组展开收起、切换模块自动手风琴；
- 模块内导航不重载内容区（应用接入、面包屑同步）；
- 切换模块后账号、头像、面包屑变化；
- 内容区内部链接（如"去预警提醒"）能反向更新外壳面包屑与地址栏；
- 评审入口能跨模块打开规则清单；
- 刷新后页面与折叠状态保持；
- 移动端抽屉打开 / 遮罩关闭；
- 无控制台报错。

结果：**28 passed / 0 failed**。
